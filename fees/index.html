Other Fees

  • Extra submission attempt: $0.05 — 3 attempts included by default; each slot above 3 costs $0.05 at vault creation (max_submissions up to 10).
  • Identity KYC (Didit): $0.50 one-time — unlocks escrows up to $10,000.
  • Skill listing: $0.10/month — list a recurring skill on the marketplace for 30 days via create_skill_listing().
  • Batch wallet trust scores: $0.10 per batch — score up to 50 XRPL addresses in one call. Single score lookups free.
