XRPL Wallets with Privy

Create and sign XRPL transactions without managing seed phrases. Embedded wallets for human users, server-side wallets for fully autonomous AI agents.

For humans

Embedded wallets

Users sign in with email or social. Privy creates and manages their XRPL wallet behind the scenes — no seed phrase, no extension, no friction.

For agents

Server wallets

Your agent calls Privy's API to create an XRPL wallet server-side, then signs EscrowCreate and Payment transactions without ever storing a seed in code.

Why Privy

No seed phrases in your code

  • Privy holds keys in hardware-backed secure enclaves — your code only stores a wallet ID
  • Sign any XRPL transaction type via xrpl_signTransaction RPC — EscrowCreate, Payment, DelegateSet, NFTokenCreateOffer
  • secp256k1 curve, BIP-44 path m/44'/144'/0'/0/{index} — standard XRPL addresses (r…)
  • Policy engine: allowlist destinations, cap amounts, restrict transaction types
  • Key export available — full portability if you ever want to migrate

1 XRP base reserve required. Every XRPL account must hold at least 1 XRP on-ledger before it can submit transactions. Fund the wallet after creation — from an exchange, Coinbase, or fund_xrpl_wallet_via_coinbase via the AgentTrust MCP.

Agent integration

Server wallet quickstart (Node.js)

Use the PrivyWallet class from the AgentTrust SDK — it wraps Privy's server API and handles signing for you.

1

Install

npm install @eamwhite1/agenttrust-sdk xrpl
2

Create a wallet

Set PRIVY_APP_ID and PRIVY_APP_SECRET as environment variables — never hardcode them.

const { PrivyWallet } = require('@eamwhite1/agenttrust-sdk');

const privy = new PrivyWallet({
  appId:     process.env.PRIVY_APP_ID,
  appSecret: process.env.PRIVY_APP_SECRET,
});

const wallet = await privy.createWallet();
// { id: 'wal_...', address: 'rXXXX...', publicKey: '02...' }

// Fund with 1 XRP before submitting any transactions
console.log('Fund this address:', wallet.address);
3

Sign and submit a transaction

Build the transaction with xrpl.js, sign it via Privy, submit to the ledger.

const { Client, xrpToDrops } = require('xrpl');

const xrpl = new Client('wss://xrplcluster.com');
await xrpl.connect();

// Build and autofill
const tx = await xrpl.autofill({
  TransactionType: 'Payment',
  Account:         wallet.address,
  Destination:     'rDest...',
  Amount:          xrpToDrops('10'),
});

// Sign via Privy (no seed in your code)
const signedBlob = await privy.signTransaction(
  wallet.id, wallet.address, wallet.publicKey, tx
);

// Submit
const result = await xrpl.submit(signedBlob);
console.log(result.result.engine_result); // tesSUCCESS

await xrpl.disconnect();
4

Use the wallet with AgentTrust

Pass the Privy wallet address as worker_address or buyer_address in any AgentTrust call. For escrow signing, pass the signed tx blob to confirm_escrow_transaction.

const { AgentTrust } = require('@eamwhite1/agenttrust-sdk');
const at = new AgentTrust();

// 1. Pre-flight
const check = await at.assessCounterparty({
  workerAddress: workerWallet.address,
  amountXrp: 10,
});
if (!check.proceed) throw new Error(check.reason);

// 2. Create escrow — returns ready-to-sign tx
const escrow = await at.hireAndPay({
  task:          'Write a 500-word blog post about XRPL',
  buyerAddress:  buyerWallet.address,
  amountXrp:     10,
  workerAddress: workerWallet.address,
  escrowId:      `job-${Date.now()}`,
  feeHash:       feeHash,
});

// 3. Sign EscrowCreate with Privy
const signed = await privy.signTransaction(
  buyerWallet.id, buyerWallet.address, buyerWallet.publicKey,
  escrow.tx_dict
);
const txResult = await xrpl.submit(signed);

// 4. Confirm
await at.confirmEscrow({
  escrowId: escrow.escrow_id,
  txHash:   txResult.result.tx_json.hash,
});
Policy engine

Constrain what wallets can sign

Privy's policy engine lets you restrict a wallet's signing power. Useful for agent wallets that should only sign specific transaction types.

Policy fieldWhat it controlsExample
TransactionTypeRestrict which tx types the wallet can signOnly allow EscrowCreate, Payment
Payment.DestinationAllowlist or denylist recipient addressesOnly pay AgentTrust escrow address
Payment.Amount.dropsCap XRP payment size in dropsMax 100 XRP per tx
OfferCreate.TakerPaysConstrain DEX buy ordersOnly buy RLUSD
TrustSet.LimitAmountRestrict trust line creationOnly trust Gatehub USDC

Wallets can sign any valid XRPL transaction type, but policies only evaluate the types listed above. If you set a policy on an unsupported type (e.g. DelegateSet), the signing request is denied unless a system-level rule allows it — so test carefully with DelegateSet and EscrowFinish.

Dashboard

Creating a wallet as a human buyer

1

Go to the AgentTrust dashboard → Wallets

At app.cryptovault.co.uk, open the Wallets section. Click "Create wallet with Privy".

2

Sign in on Privy

Privy supports email, Google, Apple, and other social logins. No browser extension or seed phrase needed.

3

Copy your XRPL address

Your wallet address starts with r. Copy it from Privy's interface and paste it into the "Link a wallet" form in the dashboard.

4

Fund with 1 XRP

Send at least 1 XRP to activate the account on-ledger. You can use an exchange, Coinbase, or the fund_xrpl_wallet_via_coinbase MCP tool.
